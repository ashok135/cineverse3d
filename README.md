# Cineverse 3D 🎬

An interactive 3D Cinema Seat Selection & First-Person Sitting Experience built with React, Three.js, React Three Fiber, and GSAP.

## ✨ Features
- **Immersive 3D Cinema Auditorium**: 100-seat stadium-style tiered theater with Front, Middle (Prime), and Balcony tiers.
- **First-Person Sitting Perspective**: Select any seat, confirm, and seamlessly transition into eye-level sitting perspective looking at the massive screen with natural head-look controls.
- **BookMyShow 2D Seat Map**: Top-right compact seat widget mirroring the BookMyShow app layout with section dividers, two-digit seat pills, and 3D screen plate.
- **House Lights ON / Movie Mode**: Toggle between bright warm auditorium house lights and atmospheric dim movie-watching ambiance.
- **TMDB Movie & Showtime Switcher**: Browse verified blockbuster releases (*Interstellar, Dune: Part Two, Oppenheimer, Avatar*), change auditoriums, and experience dynamic showtime seat occupancy.
- **Digital E-Ticket**: Instant confirmation modal with movie details, barcode, and seat credentials.

## 🛠 Tech Stack
- **React 18**
- **Three.js** & **@react-three/fiber**
- **@react-three/drei**
- **GSAP** (GreenSock Animation Platform)
- **Vite**

## 🚀 Getting Started


### Run Locally
```bash

```

### Build for Production
